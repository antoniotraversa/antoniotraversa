# antoniotraversa.it

Base professionale React + Vite, pulita e pronta per essere espansa con componenti reali.

## Avvio rapido

1. Installa le dipendenze:
    npm install
2. Avvia il server di sviluppo:
    npm run dev
3. Build produzione:
    npm run build
4. Preview locale build:
    npm run preview

## Struttura attuale

- src/main.jsx: bootstrap React.
- src/App.jsx: shell principale del sito.
- src/index.css: reset globale + design tokens (variabili CSS).
- src/App.css: layout e classi riutilizzabili.
- src/components/: mantenuta intatta per sviluppo componenti.
- src/pages/: mantenuta intatta per sviluppo pagine.
